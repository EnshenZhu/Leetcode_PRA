# 389. Find the Difference

&zwnj;**Difficulty**&zwnj;: Easy
&zwnj;**Topics**&zwnj;: 
&zwnj;**Companies**&zwnj;: 

You are given two strings `s` and `t`.

String `t` is generated by random shuffling string `s` and then adding one more letter at a random position.

Return the letter that was added to `t`.

## Example 1:
&zwnj;**Input**&zwnj;: `s = "abcd", t = "abcde"`
&zwnj;**Output**&zwnj;: `"e"`
&zwnj;**Explanation**&zwnj;: `'e'` is the letter that was added.

## Example 2:
&zwnj;**Input**&zwnj;: `s = "", t = "y"`
&zwnj;**Output**&zwnj;: `"y"`

## Constraints:
- `0 <= s.length <= 1000`
- `t.length == s.length + 1`
- `s` and `t` consist of lowercase English letters.
